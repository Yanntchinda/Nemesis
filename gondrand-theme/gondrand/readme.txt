Thème Gondrand à importer dans WordPress.

== Installation ==

1. Dans WordPress : Apparence → Thèmes → Ajouter → Téléverser un thème
2. Choisissez gondrand-wordpress-theme.zip
3. Cliquez sur Installer puis Activer
4. Ouvrez https://votre-domaine.fr — le site Gondrand remplace Twenty Twenty-Five

== Devis ==

Apparence → Personnaliser → Gondrand → E-mail des demandes de devis.

Par défaut : l’e-mail administrateur WordPress.

== Compte admin ==

https://votre-domaine.fr/wp-admin reste disponible.
