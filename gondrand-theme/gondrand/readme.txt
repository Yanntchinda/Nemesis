Thème Travex Global Forwarding à importer dans WordPress.

== Installation ==

1. Dans WordPress : Apparence → Thèmes → Ajouter → Téléverser un thème
2. Choisissez gondrand-wordpress-theme.zip
3. Cliquez sur Installer puis Activer
4. Ouvrez https://votre-domaine.fr — le site Travex Global Forwarding remplace Twenty Twenty-Five

== Modifier le site ==

Apparence → Personnaliser → Travex — contenu du site

- Slider 1 à 6 : image, titre, texte, lien
- Logo, intro, cartes, coordonnées, menu, textes
- CSS additionnel : Apparence → Personnaliser → CSS additionnel

Un champ vide conserve le contenu d’origine.

== Devis ==

Apparence → Personnaliser → Travex Global Forwarding → E-mail des demandes de devis.

Par défaut : l’e-mail administrateur WordPress.

== Compte admin ==

https://votre-domaine.fr/wp-admin reste disponible.
